# Сайт repiq.ru

Это статический сайт для домена `repiq.ru`.

## Что внутри

- `index.html` — главная страница приложения «Репетитор AI».
- `privacy.html` — политика конфиденциальности для RuStore и сайта.
- `ai-pro.html` — черновая страница будущей AI Pro подписки.
- `repiq-board.html` и `board-v2/` — раздел RepIQ Board.
- `.nojekyll` — служебный файл на случай публикации через GitHub Pages.

## RepIQ Board

Статическая часть доски лежит в `board-v2/index.html` и работает прямо на сайте: открывает PDF, позволяет писать на слайде и листах комментариев, сохраняет итоговый PDF.

Конвертация PPT/PPTX в PDF подготовлена в `board-v2/app.py`. Для нее нужен отдельный Python-сервис с зависимостями из `board-v2/requirements.txt` и установленным LibreOffice на сервере.

## AI-генерация презентаций

Backend для AI-презентаций лежит в `server/`.

Переменные окружения на TimeWeb:

- `OPENAI_API_KEY` — ключ OpenAI Platform.
- `AI_MODEL` — модель для текстовой структуры презентации. Если не указать, используется `gpt-4.1-mini`.

Запуск backend:

```bash
pip install -r server/requirements.txt
uvicorn server.main:app --host 0.0.0.0 --port 8000
```

Endpoint:

- `POST /api/ai/presentation/create`

## AI-презентация RepIQ Board

Модуль находится в `cloudflare-worker/` и использует Cloudflare Workers AI без ключа OpenAI и без отдельного сервера TimeWeb.

Схема работы:

1. Worker получает тему, предмет, класс и параметры урока.
2. Qwen формирует структуру слайдов, формулы, примеры, шаги решения и типы визуализаций.
3. Для подходящих предметов FLUX создаёт одну тематическую обложку. Математические и технические темы используют точные локальные графики и схемы.
4. `board-v2/static/ai-presentations.js` выбирает разные макеты и оформляет слайды в браузере.
5. Готовая презентация сразу открывается в RepIQ Board.

Доступны автоматические стили для математики, языков, географии, естественных наук, истории, информатики и универсального урока. Есть макеты для формул, пошаговых примеров, карточек, сравнения, практики и итогов. Если сильная модель временно недоступна, Worker автоматически использует быструю резервную модель.

Методическая структура едина для всех предметов: разминка и цель, объяснение, несколько примеров с разбором, парная или групповая работа, самостоятельная работа уровней «База / Стандарт / Вызов», игровой раунд, конспект-обобщение и домашнее задание последним слайдом. Для полноценной структуры создаётся от 10 до 16 слайдов.

После деплоя Worker его адрес нужно один раз вписать в:

```text
board-v2/static/ai-config.js
```

Подробная инструкция: `cloudflare-worker/README_RU.md`.

На одну презентацию создаётся не более одной генеративной картинки. Видео, realtime и web search не используются.

## Как загрузить на хостинг

1. Открыть панель хостинга.
2. Найти файловый менеджер сайта `repiq.ru`.
3. Загрузить содержимое этой папки в корень сайта.
4. Проверить, что открывается `https://repiq.ru`.

Основной сайт статический и не требует сервера или базы данных. RepIQ Board для конвертации PPT/PPTX и будущего AI-модуля требует отдельный backend.
