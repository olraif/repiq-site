# Бесплатный AI для RepIQ Board

Этот Worker использует бесплатный лимит Cloudflare Workers AI. Ключ OpenAI не нужен.

Модели:

- `@cf/qwen/qwen3-30b-a3b-fp8` — основное содержание урока;
- `@cf/meta/llama-3.1-8b-instruct-fast` — резервная модель;
- `@cf/black-forest-labs/flux-1-schnell` — одна необязательная обложка.

Если генерация обложки не сработает, презентация продолжит строиться с локальными графиками и схемами.

## Развёртывание

1. Создать бесплатный аккаунт Cloudflare.
2. Открыть `Workers & Pages` и создать Worker из Git-репозитория.
3. Указать корневую директорию `cloudflare-worker`.
4. Команда развёртывания: `npx wrangler deploy`.
5. После первого деплоя скопировать адрес вида
   `https://repiq-board-ai.<имя>.workers.dev`.
6. Вставить этот адрес в `board-v2/static/ai-config.js`.

Проверка:

```text
https://<адрес-worker>/health
```

Ожидаемый ответ: `{"ok":true,...}`.

Платный тариф Cloudflare подключать не нужно. При исчерпании бесплатного лимита генерация временно перестанет отвечать, но автоматического списания не будет.
