Политика конфиденциальности приложения «Репетитор AI»

Редакция от 21 мая 2026 года

Настоящая политика описывает, какие данные обрабатывает приложение «Репетитор AI» и как пользователь может управлять своими данными.

1. Общая информация

«Репетитор AI» — приложение для учёта учеников, групп, расписания, оплат, баланса и личных дел репетитора.

Разработчик: Олеся Сайфуллина.

Сайт приложения: https://repiq.ru.

2. Какие данные может вводить пользователь

Пользователь самостоятельно вводит данные в приложение. Это могут быть:

  • имена учеников;
  • предметы, классы и формат занятий;
  • телефоны ученика и родителя;
  • имя родителя;
  • расписание занятий;
  • данные о группах;
  • суммы и даты оплат;
  • комментарии к ученикам, занятиям, оплатам и личным делам;
  • настройки рабочего времени и напоминаний.

3. Где хранятся данные

В текущей версии данные хранятся локально на устройстве пользователя. Разработчик не получает, не просматривает и не передаёт данные учеников, родителей, расписания и оплат третьим лицам.

4. Резервная копия

Пользователь может создать резервную копию данных. Резервная копия сохраняется в виде JSON-файла в папку «Загрузки» устройства или в место, выбранное системой.

Файл резервной копии может содержать все данные, которые пользователь внёс в приложение: учеников, родителей, телефоны, расписание, оплаты, группы, комментарии и настройки.

Пользователь самостоятельно решает, где хранить файл резервной копии и кому его передавать. Для защиты данных рекомендуется не отправлять файл посторонним лицам.

5. Разрешения устройства

Приложение может использовать следующие разрешения:

  • доступ к интернету — зарезервирован для будущих AI-функций и сетевых возможностей;
  • вибрация — для напоминаний перед уроком, если пользователь включил такую настройку;
  • запись во внешнее хранилище на старых версиях Android — для сохранения резервной копии в папку «Загрузки».

6. AI-функции

AI-разделы приложения находятся в неактивном состоянии. При будущем подключении AI-функций политика конфиденциальности будет обновлена до запуска таких функций.

7. Удаление данных

Пользователь может удалять данные внутри приложения: учеников, группы, оплаты, занятия и личные дела.

Также пользователь может удалить все данные приложения средствами Android: настройки устройства → приложения → «Репетитор AI» → очистить данные или удалить приложение.

8. Изменения политики

Политика может обновляться при изменении функций приложения, появлении аккаунтов, синхронизации, платежей или AI-модулей.

Для связи используйте контактные данные, указанные в карточке приложения в RuStore.
